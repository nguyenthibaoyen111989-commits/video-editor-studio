# Video Editor Studio

Bây giờ tôi đang build ra một ứng dụng edit video tôi rất thích vì nó tiện và có đủ tính năng mà tôi muốn, từ giao diện trên bạn hãy giúp tôi thiết kế một giao diện tương tự 100% từ hình ảnh đến màu sắc đến tính năng và đầy đủ các thành phần để tôi sử dụng và nâng cấp cho sau này,.. Hãy giúp tôi làm chính xác nhé, phần media nào mà còn thiếu thì tôi sẽ bổ sung sau.
